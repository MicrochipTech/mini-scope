# Card 4.1: the Script tab (selection, Check, Problems)

Start: HEAD d44cc42, tree clean. No MDB was run.

## What changed

- `gui/script_tab.py` (new): the Script tab. `scope_gui.py` only calls `script_tab.build(get_table, get_baud, pick_file)`
  and hands in what it needs; there is no second import of `scope_gui`.
- `gui/scope_gui.py`: the page has two tabs. Header, port row and ELF row stay above the tabs, because both tabs use
  them. Everything else that existed is in the Scope tab, unchanged except for 4 spaces of indentation
  (`git diff -w` shows only the new lines). The tab panels use `keep-alive`, so the chart survives a tab change.
- ELF list: new `load_vars(path)` takes the names from `elf_vars.VarTable` (`motor.run`, `phase[1].current`), the type
  from the DWARF data. An ELF without DWARF falls back to the old `load_symbols`. The table is kept in `app['table']`
  and is what Check uses. SIM uses `VarTable.from_symbols(SYMBOLS, SYMBOL_TYPES)`.
- New option `--config FILE` (settings file instead of `mini-scope.json`), so a test does not touch the real one.
- `gui/tune_check.py`: one small hook, `check_compile(path)`, stage 1 alone (no table). Nothing else changed.
- `tests/test_gui.py`, `tests/requirements-dev.txt` (playwright), screenshots in `docs/evidence/m4/`.

## Behaviour

- Selection row: list of all `.py` in `scripts/` (read again each time the list opens and when the tab opens),
  Browse (existing `pick_file`) adds a file from another folder (shown as `name.py (other folder)`), the first comment
  line of the script next to the list, Open, Check. Run, Abort and Probe are there and disabled (card 4.2).
- The selection and the added files are saved with Save in `mini-scope.json`, key `script`
  (`selected`, `extra`; paths inside the project are stored relative).
- Stage 1 runs when a file is selected and when its time stamp (mtime, size) changes, polled every 1 s.
- Check: stages 1 to 3 through `tune_check.check_script`, in a worker thread, no connection, nothing written. Without
  a VarTable (no ELF loaded) only stage 1 runs and the status line says an ELF is needed for stages 2 and 3.
- Problems: one row per problem, `tune_startup.py:19: error: text`, with the rule code as a badge; errors red,
  warnings orange. A click shows the line in a read-only code view, highlighted and scrolled to the middle.
- Open: `os.startfile(path, 'edit')`, on `OSError` Notepad; never the default action. Other systems: `open -t`,
  `xdg-open`.
